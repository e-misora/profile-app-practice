# profile-app-practice

## 概要
COACHTECH 教材 Tutorial 9-1「Laravel基礎ハンズオン」で作成した成果物です。
コントローラーでデータを準備し、Bladeビューに渡して表示する「自己紹介ページ」を作成しました。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Blade テンプレート

## 学んだこと
- Bladeビューにデータを渡すcompact関数の書き方
- @foreachなどでのnddn変数の表示

## 動作確認
http://localhost/profile にアクセス  
+ 名前「山田太郎」が表示される  
+ 年齢「25歳」が表示される  
+ 趣味がリスト形式で表示される（プログラミング、読書、旅行））
